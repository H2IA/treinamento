# Treinamento H2IA

Este é o material de estudo do treinamento do Hub2IA da UFPel. Aqui você encontra uma sequência de leituras, vídeos e atividades para começar a estudar inteligência artificial e implementar os primeiros algoritmos.

Você pode acompanhar o percurso mesmo que não tenha participado dos encontros. Comece pelas ferramentas se ainda está aprendendo Python. Se já consegue escrever funções e trabalhar com listas, siga para a semana 4, onde começa o estudo de buscas.

## Como estudar

Leia a apresentação de cada semana antes de abrir os links. Ela indica o que observar nos materiais e como o assunto se conecta à atividade. Não é preciso consumir todas as referências de uma vez: siga o roteiro e use os materiais complementares quando precisar de outra explicação ou quiser aprofundar.

Enquanto estuda, pare para refazer um exemplo, prever o próximo passo de um algoritmo ou alterar um trecho de código. Entender uma explicação e conseguir usá-la são coisas diferentes. As perguntas ao longo das páginas ajudam a perceber o que ainda precisa de atenção.

Os números das semanas organizam o percurso. Se você está retomando, use-os como ordem de estudo e avance conforme conseguir realizar as atividades.
